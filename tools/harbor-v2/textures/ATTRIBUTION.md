# Harbor V2 source texture attribution

The following source textures are provided by Poly Haven under CC0 1.0 and are
embedded into generated Harbor GLB assets:

- Rusty Corrugated Iron  
  https://polyhaven.com/a/rusty_corrugated_iron
- Concrete  
  https://polyhaven.com/a/concrete
- Wood Planks  
  https://polyhaven.com/a/wood_planks
- Asphalt 02  
  https://polyhaven.com/a/asphalt_02

Warehouse V2 PBR material pass (`warehouse-pbr/`, 1K source maps, CC0):

- Concrete Floor Worn 001 (`MAT_CONCRETE`)  
  https://polyhaven.com/a/concrete_floor_worn_001
- Box Profile Metal Sheet (`MAT_CORRUGATED_RED`)  
  https://polyhaven.com/a/box_profile_metal_sheet
- Metal Plate 02 (`MAT_GALVANIZED`, `MAT_SAFETY_YELLOW` derivatives)  
  https://polyhaven.com/a/metal_plate_02
- Blue Metal Plate (`MAT_STEEL_NAVY`)  
  https://polyhaven.com/a/blue_metal_plate
- Rusty Corrugated Iron (`MAT_ROOF_DARK` derivative)  
  https://polyhaven.com/a/rusty_corrugated_iron
- Wood Planks (`MAT_WOOD`)  
  https://polyhaven.com/a/wood_planks

`warehouse-pbr/_derived/` holds the game-ready 512/1024 px Base Color, Normal
(OpenGL) and ORM (AO / roughness / metalness) maps generated from those
sources; `spec.json` records the per-material tile size in meters.

derivation via `tools/harbor-v2/zones/zone_textures.py`:

- Weathered Planks (`wood_weathered`) — https://polyhaven.com/a/weathered_planks
- Wood Planks (`wood_interior`) — https://polyhaven.com/a/wood_planks
- Red Brick 03 (`brick`) — https://polyhaven.com/a/red_brick_03
- Stone Tiles 02 (`stone_paving`) — https://polyhaven.com/a/stone_tiles_02
- Leafy Grass (`lawn`) — https://polyhaven.com/a/leafy_grass

- Rock Boulder Dry (`rock`) — https://polyhaven.com/a/rock_boulder_dry
- Bark Brown 02 (`bark`) — https://polyhaven.com/a/bark_brown_02

- Rusty Corrugated Iron (`rust_dark`) — https://polyhaven.com/a/rusty_corrugated_iron

Leaf, grass, reed, grating and palette cards in the zone `_derived/` folders are
procedural (`tools/harbor-v2/zones/foliage_cards.py`, `zone_kit.palette`).

Runtime builds use compressed derivatives generated by the Harbor Blender and
glTF Transform pipeline.
